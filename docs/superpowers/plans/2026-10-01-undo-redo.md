# Undo/Redo fix — table + raw

**Date:** 2026-10-01  
**Status:** code done — F5 smoke pending (v6)

## Symptom

Undo flaky after clipboard paste; extra undo past end; history dies mid-session.

## Root causes

1. Debounced `editRaw` (120ms) can land **after** undo in the host queue → paste rewrite undoes the undo.
2. `ownApply` 100ms gate too short for large paste `applyEdit` → late change event wiped mirror stacks.
3. Hybrid `executeCommand('undo')` (removed in v4) polluted VS Code stack.

## Fix (v5)

1. Host `gen` on every sync; `edit`/`editRaw` carry gen — **stale dropped**.
2. `recentOwn` content gate 2s; never wipe stacks while own writes pending.
3. Push/plan history **only after** successful `applyEdit`.
4. Raw: bump epoch on host sync (cancel pending emit); paste flushes at 0ms debounce.
5. Mirror-only CmdZ; empty = no-op; serialized queue.

## v6 — survive leave/re-enter

`historyFor(uri)` module map holds undo/redo for session. Cleared on `onDidCloseTextDocument` or tip mismatch (file edited elsewhere). Not persisted across extension host restart (`ponytail:` full-text stacks in workspaceState = too heavy).

## Test

- Reload Extension Host.
- Raw: paste big chunk → ⌘Z restores pre-paste once; spam undo stays stable.
- Edit → close tab → reopen same file → ⌘Z still works.
- 3 edits → 3 undos → 4th no-op.
